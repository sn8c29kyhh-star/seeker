## 🧪 Day 0 Verification Gate (Audit Before Day 1 Kickoff)

Do not allow the student to begin Day 1 until all 6 items are physically verified:

- [ ] **Google Gemini Desktop**: Installed, pinned to Windows Taskbar, and verified operational.
- [ ] **Google Antigravity**: Installed and logged in with default workspace layout.
- [ ] **Google Docs & Sheets**: Bookmarked with offline extension enabled.
- [ ] **Windows Directory Structure**: Student confirmed `C:\QA_Training\` has all 5 subfolders:
  - `01_Requirements\`
  - `02_Test_Cases\`
  - `03_Defect_Screenshots\`
  - `04_SQL_Scripts\`
  - `05_Postman_Collections\`
- [ ] **Chrome DevTools (`F12`) & Snipping Tool (`Win + Shift + S`)**: Tested by student.
- [ ] **Day 0 AI Dry-Run Exercise**: Student submitted `Indian_Mobile_Login_Negative_Scenarios.xlsx` in `02_Test_Cases`. Columns verified for Scenario ID, Description, Steps, and Expected Result.
