# 🧪 Day 1 Hands-On Exercise: Verification vs Validation Matrix

In this exercise, you will classify real-world software activities as either **Verification** or **Validation**, and justify your reasoning.

---

## 🎯 Task Instructions

1. Open **Google Sheets** (or Excel).
2. Create a new sheet named: `Day01_Verification_vs_Validation.xlsx`.
3. Create 4 columns:
   - `Activity ID`
   - `Scenario / Activity Description`
   - `Classification (Verification or Validation)`
   - `Justification / Reason`

---

## 📋 Scenarios to Classify

Classify the following 8 engineering activities:

| Activity ID | Scenario Description |
| :--- | :--- |
| `ACT_01` | Reviewing the Business Requirement Document (BRD) for an online banking portal to identify missing edge cases in money transfer rules. |
| `ACT_02` | Clicking the 'Submit' button on an e-commerce checkout page with an invalid credit card number to verify that a red error alert appears. |
| `ACT_03` | Participating in a sprint walkthrough of database entity relationship diagram (ERD) with the database architect. |
| `ACT_04` | Testing a flight search feature by inputting arrival date before departure date to confirm the system prevents booking. |
| `ACT_05` | Performing a peer code inspection of an authentication service before the code is merged into the staging branch. |
| `ACT_06` | Conducting a User Acceptance Testing (UAT) session with hospital staff to confirm patient record creation matches their clinical workflow. |
| `ACT_07` | Verifying that the API specification document lists all required HTTP status codes for the user login endpoint. |
| `ACT_08` | Using Chrome DevTools to inspect if an image on the homepage loads within 2 seconds. |

---
