# 📅 Day 11: Hands-on Jira Execution & Defect Logging

> **Theme**: Creating, linking, and managing real bug tickets inside Jira with industry-grade details.

---

## 🎯 Learning Objectives

By the end of today, you will:
- [ ] Create detailed Bug tickets inside your Jira workspace.
- [ ] Fill all key defect fields: Summary, Description, Steps to Reproduce, Severity, Priority, Environment, Components, and Fix Version.
- [ ] Attach annotated screenshots and error logs.
- [ ] Link bugs to parent User Stories.

---

## 🛠️ Hands-On Task for Today

1. Log into your Jira workspace created on Day 10.
2. In your `E-Commerce Store QA` project, click the **+ Create** button in the top navigation.
3. Select Issue Type: **Bug**.
4. Log **3 realistic bugs** using the following scenarios:
   - **Bug 1**: `[Checkout] Payment gateway fails with error code 400 when paying with Rupay Debit card.`
     - Severity: High, Priority: P1.
     - Add reproducible steps, expected/actual results, and environment info.
   - **Bug 2**: `[Product Details] Quantity increment (+) button allows entering negative numbers.`
     - Severity: Medium, Priority: P2.
   - **Bug 3**: `[Profile Page] User avatar profile picture upload accepts .exe files instead of image files.`
     - Severity: High (Security vulnerability), Priority: P1.
5. Practice transitioning a bug ticket through the workflow:
   - Move from `To Do` -> `In Progress` -> `In Review` -> `Done`.
6. Export the Jira issues list or take screenshots of each bug ticket. Save to:
   `C:\QA_Training\03_Defect_Screenshots\Day11_Jira_Bug_Tickets\`.
