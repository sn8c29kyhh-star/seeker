> **Theme**: Crafting an ATS-friendly, high-conversion Manual QA resume that highlights practical STLC skills, Jira, SQL, and Postman API testing.

---

## 🎯 Learning Objectives

By the end of today, you will:
- [ ] Understand ATS (Applicant Tracking System) keywords for Manual QA job descriptions.
- [ ] Structure your resume sections: Summary, Technical Skills, Live Projects, Academic Background, Certifications.
- [ ] Showcase your live portfolio: Shareable Google Drive links to your 50+ Test Cases, RTM, and Jira Bug Reports.

---

## 📄 Key Sections for Your Manual QA Resume

### 1. Professional Summary (Example)
> *"Detail-oriented and certified Quality Assurance Analyst with hands-on expertise in Software Testing Life Cycle (STLC), Black-Box Test Design (ECP, BVA), Defect Management in Jira, SQL Backend Data Validation, and API Testing using Postman. Proven ability to design comprehensive 50+ test suites and execute end-to-end sprint simulations on e-commerce and HRMS web applications."*

### 2. Core Technical Skills Table
- **Testing Methodologies**: STLC, SDLC, Agile Scrum, Functional Testing, Regression, Smoke/Sanity, Re-testing, Cross-Browser Testing.
- **Test Design**: Equivalence Class Partitioning (ECP), Boundary Value Analysis (BVA), Decision Tables, Requirement Traceability Matrix (RTM).
- **Defect Management & Agile Tools**: Atlassian Jira Cloud, Zephyr Squad, GitHub Issues & Kanban Boards.
- **Backend & Database Validation**: SQL (MySQL / SQLite), SELECT, WHERE, Aggregations, INNER/LEFT Joins.
- **API Testing**: Postman, RESTful APIs, HTTP Status Codes, JSON Payloads, Collection Runner.
- **Productivity & Utilities**: Chrome DevTools, Google Sheets, Microsoft Excel, Snipping Tool.

### 3. Featured Project: Live E-Commerce Web QA Project
- Designed and executed a comprehensive 50+ test case suite in Google Sheets covering Auth, Search, Cart, and Checkout flows.
- Logged 10+ high-severity functional and UI defects in Jira with reproducible steps and DevTools error logs.
- Executed database validation queries to confirm data integrity between UI form submissions and SQL database tables.
- Tested REST API endpoints in Postman verifying `200`, `201`, `400`, and `404` status codes.
