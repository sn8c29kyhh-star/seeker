## 🎙️ Mock Interview Question Bank

### Section 1: Core Testing Principles (Warm-up)
1. **Explain the difference between Verification and Validation.**  
   *(Hint: Static vs Dynamic, "Are we building the product right" vs "Are we building the right product")*
2. **What is the difference between Regression Testing and Re-testing?**
3. **What is Equivalence Class Partitioning and Boundary Value Analysis? Give an example.**
4. **Walk me through the Defect Life Cycle from 'New' to 'Closed'.**
5. **What is the difference between Severity and Priority? Give a high severity, low priority example.**

### Section 2: Situational & Behavioral Scenarios
6. **"How would you test a simple ballpoint pen?"**  
   *(Structure answer: Functional [ink flow, writing smooth], Non-functional [grip, durability, weight], Negative/Edge [writing upside down, on wet paper, high altitude])*
7. **"A developer rejects your bug as 'Not a Bug' or 'Works as Expected'. What exact steps do you take?"**  
   *(Steps: 1. Re-verify steps and screenshots against latest build. 2. Cross-reference official SRS/User story acceptance criteria. 3. Politely reach out to developer to reproduce together locally. 4. If ambiguity persists, involve Product Owner/QA Lead to clarify requirements.)*
8. **"You find a critical blocker bug 2 hours before a major production release. What do you do?"**

### Section 3: SQL & Database Validation
9. **Write an SQL query to find the second highest salary from an `employees` table.**
10. **Explain the difference between `INNER JOIN` and `LEFT JOIN`. When would a QA tester use a `LEFT JOIN`?**
11. **What is the difference between `DELETE`, `TRUNCATE`, and `DROP`?**
12. **How does `HAVING` differ from `WHERE` in a `GROUP BY` query?**

### Section 4: API Testing via Postman
13. **What is the difference between HTTP status codes `401 Unauthorized` and `403 Forbidden`?**
14. **What are the common HTTP methods used in REST APIs and what does each do?**
15. **What is the difference between Query Parameters and Path Parameters in Postman?**
